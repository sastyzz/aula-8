# 🎵 Inicie sua Carreira Musical

Um projeto desenvolvido em HTML e CSS com o objetivo de apresentar o universo da música, incentivar novos artistas e compartilhar informações sobre estilos musicais, instrumentos e caminhos para iniciar uma carreira musical.

## 📌 Sobre o projeto

O site reúne conteúdos informativos e motivacionais para pessoas interessadas em música, desde quem está começando até quem deseja conhecer melhor o mercado musical e suas possibilidades.

A proposta é explorar a música como forma de expressão artística, cultural e profissional.

## 📚 Páginas do projeto

O site é dividido em seis páginas:

| Página | Conteúdo |
|---|---|
| Home | Apresentação e incentivo ao início de uma carreira musical. |
| Histórias | Trajetórias e inspirações de artistas. |
| Modalidades | Estilos e gêneros musicais brasileiros e internacionais. |
| Instrumentos | Informações sobre instrumentos musicais. |
| Onde começar | Orientações para dar os primeiros passos na música. |
| Como se profissionalizar | Reflexões sobre carreira e profissionalização musical. |

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e apresentação visual.
- **Git e GitHub:** versionamento e hospedagem do código.

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Entre na pasta `html`.
4. Abra o arquivo `p1.html` em seu navegador.

Não é necessário instalar dependências ou configurar um servidor para visualizar o projeto localmente.
